# 🤖 Basic Chatbot Using Python

## CodeAlpha Python Internship - Task 4

---

## 📌 Project Overview

This project is a simple interactive chatbot developed using Python.

The chatbot communicates with the user through the command-line interface and responds to predefined questions and commands.

The project demonstrates fundamental Python programming concepts such as:

- Functions
- Conditional statements
- Loops
- String processing
- Exception handling
- User input
- Date and time handling
- Modular programming

---

## 🎯 Objective

The main objective of this project is to create a basic chatbot that can interact with users and provide useful responses based on their input.

The chatbot is designed to simulate a simple human-like conversation using predefined responses.

---

## ✨ Features

The chatbot provides the following features:

- 👋 Greeting responses
- 💬 Basic conversation
- 🤖 Chatbot name information
- 🕐 Current time
- 📅 Current date
- 🧮 Simple calculator
- 📚 Help command
- 🐍 Python-related response
- 💼 Internship-related response
- 👋 Goodbye command
- ⚠️ Invalid input handling

---

## 🛠️ Technologies Used

- Python 3
- Python datetime module
- Command Line Interface

No external libraries are required.
